# a11y-sdk

Accessibility context for this repo lives in `.a11y/context.md`. Read it before generating or modifying any UI component, template, or markup. It defines the WCAG 2.1 AA rules and component patterns (modal/dialog, form, data table, navigation, toast/alert) this project enforces.

Per-pattern deep-dives are in `.a11y/rules/`. Consult them when working on focus management, ARIA state, live regions, or keyboard interaction.
